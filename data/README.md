# Data

These files come from the course's capstone pack (`05_Datasets`). The full field-by-field description is in
the pack's Dataset Guide.

| File | Records | Use |
|---|---|---|
| `development_tickets.json` | 500 | Develop and train against freely |
| `validation_tickets.json` | 80 | Check progress; the gate run uses this set |
| `ground_truth_responses.json` | 200 | Reference answers for development tickets (`must_mention`, `must_not_claim`) |
| `documentation.json` | 29 | The knowledge base that retrieval searches |

The hidden 120-ticket assessment set is not distributed. It uses the same schema as the validation file.
