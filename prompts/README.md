# Prompt register

Every prompt the system uses lives in this folder as its own file, and gets a row here.
Change the version whenever the text changes, and say why in the change log.

- `build/` holds prompts that run inside the system (answer drafting, escalation summaries).
- `evaluation/` holds prompts used to judge output (for example, checking for unsupported claims).
